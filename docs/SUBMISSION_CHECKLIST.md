# Pokétran final package checklist (do not substitute for official rubric)

The new build guide (especially pages 19–20 and 29–35) requires an **individually uploaded** complete final archive per student. This repository is a source starting point; most evidence items are not provided yet.

## Source and app verification

- [ ] Written instructor-team proposal approval has been obtained and documented.
- [ ] Flutter analyzer and tests passed on the student's machine; results saved.
- [ ] App functionality tested offline and after restart on two devices/emulators.
- [ ] The Android **release APK** installs, starts, and works offline.
- [ ] Both SQLite entities CRUD, parent deletion, limits, and errors demonstrated.
- [ ] SharedPreferences, coach choices, the five cases, and helper baseline verified.
- [ ] Genuine peer usability feedback caused a documented code revision.

## GitHub and task-management evidence

- [ ] New GitHub repository accessible to instructor (public or instructor added).
- [ ] Each real team member made at least 20 meaningful commits over real work.
- [ ] Feature branches, code reviews/PRs and clearly named commits visible.
- [ ] ClickUp board tracks owners, acceptance criteria, due dates, limits and links.
- [ ] Four actual dated ClickUp screenshots captured at the required checkpoints.
- [ ] `Kanban_Contribution_Evidence.pdf` contains readable snapshots, task-to-code/test trace, flow/reflection, privacy and link verification.
- [ ] README identifies actual board URL and evidence file location.

## Documents and presentation

- [ ] Approved proposal Word document, instructor approval evidence.
- [ ] `PROJECT_REPORT.pdf`: actual features, technical choices, problems, fixes, testing results and individual contributions.
- [ ] Signed student acknowledgment PDF/legible image(s) with genuine team signatures.
- [ ] Architecture documentation / README with screenshots, setup and instructions.
- [ ] `AI_FEATURE.md` reflects final observed evaluations and limitations.
- [ ] `AI_Usage_Log.md` accurately discloses assistance (and any further sessions).
- [ ] Slide deck (`.pptx`) and questions-only Word selection using official full question text and IDs.
- [ ] One rehearsed **20–25-minute** team video, uploaded with accessible YouTube link; app, VS Code, technical design, testing, contributions, and curated answers covered.
- [ ] At least two questions from each required category; required identifiers I1, I2, D1, D2, R4; use instructor's Q&A source for accurate text.
- [ ] Source code, GitHub link, YouTube link, APK, and all documentation in final ZIP; ZIP filenames follow instructor's naming rules.
- [ ] Every member uploads individually and verifies the iCollege receipt.

## Important distinctions

`Poketran_Flutter_Project.zip` from ChatGPT is **not** the submission ZIP above: it has source/docs/tests, but does not have genuine approval/signatures/ClickUp evidence, a built APK, a recorded video, or a verified passing test run. These cannot be generated truthfully by a source-code edit.
